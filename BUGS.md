# Найденные ошибки

Проблемы, найденные при разработке и проверке. Для каждой: как воспроизвести и что сделано.

## Этап 1. Аккаунты

### Приложение не узнавало о настроенных аккаунтах
- **Шаги:** задать `SUPABASE_URL` и `SUPABASE_ANON_KEY`, пройти знакомство.
- **Ожидалось:** экран «Сохранять прогресс?».
- **Было:** сразу главная; в консоли предупреждение «unreachable code».
- **Причина:** вызов `initAccounts()` при правке попал внутрь функции `openChatPlan` после `return`.
- **Исправлено:** вызов перенесён в конец `js/app.js`, после первой отрисовки.

### «Не сейчас» не прятало подсказку про аккаунт на экране «Готово»
- **Шаги:** гостем завершить первый план, нажать «Не сейчас».
- **Было:** карточка оставалась на месте.
- **Причина:** экран «Готово» строился один раз и не обновлялся.
- **Исправлено:** у экрана появился `update`, который скрывает подсказку.

### Неверный пароль показывал общий текст ошибки
- **Шаги:** войти с неправильным паролем.
- **Ожидалось:** «Почта или пароль не подошли».
- **Было:** «Не получилось. Это не ты…».
- **Причина:** Supabase Auth кладёт код ошибки в `error_code`, старые версии отдают только текст.
- **Исправлено:** код читается из `error.code`, а если его нет, распознаётся по тексту (`authErrorMessage`).

### После выхода из аккаунта открывалась главная вместо профиля
- **Шаги:** Профиль → «Выйти».
- **Было:** переход на главную, человек терял место.
- **Исправлено:** после выхода остаётся экран профиля с карточкой гостя.

### Ошибка поля не исчезала во время исправления
- **Шаги:** отправить пустую форму регистрации, начать вводить почту.
- **Было:** красный текст «Впиши почту» висел до следующей отправки.
- **Исправлено:** ошибка поля сбрасывается при вводе в это поле.

## Этап 2. Профиль

### «Сменить пароль» отправлял форму как сброс по ссылке
- **Шаги:** Профиль → «Сменить пароль» → ввести пароль → «Сохранить пароль».
- **Было:** после сохранения открывалась главная, как после сброса по ссылке из письма.
- **Причина:** форма режима `change` отправлялась с типом `reset`.
- **Исправлено:** форма отправляет свой тип, после смены пароля человек возвращается в профиль.

### Тестовый сервер без переменных Supabase прятал вход
- **Шаги:** запустить приложение без `SUPABASE_URL`, открыть профиль.
- **Было:** нет кнопок входа (ожидаемо, но в тесте это выглядело как ошибка).
- **Вывод:** без настроенного Supabase приложение честно работает только в режиме гостя. Это записано в README.

## Этап 3. Серия

### На экране серии число повторялось дважды
- **Шаги:** закрыть план, открыть экран серии.
- **Было:** крупное «4» и под ним заголовок «4 дня подряд».
- **Исправлено:** под крупным числом только «дня подряд»; для скринридера число читается один раз.

### Экран серии не восстанавливался после перезагрузки
- **Шаги:** открыть «Серия», обновить страницу.
- **Было:** открывалась главная.
- **Исправлено:** экран серии сохраняется в сессии, как остальные.

### Почта вместо имени рвалась по буквам на 320px
- **Шаги:** зарегистрироваться без имени, открыть профиль на узком экране.
- **Было:** «v@exa / mple.c / om» в три строки.
- **Исправлено:** без имени показывается часть адреса до @, полный адрес — в карточке аккаунта.

## Этап 4. Библиотека

### Подпись вкладки «Библиотека» обрезалась на 320px
- **Шаги:** открыть приложение на ширине 320px.
- **Было:** «Библиоте…» в нижней панели.
- **Исправлено:** вкладка называется «Книги», заголовок раздела остаётся «Библиотека».

### Темы занимали три строки на узком экране
- **Было:** пять кнопок тем переносились и сдвигали книги вниз на полэкрана.
- **Исправлено:** темы в одну строку с горизонтальной прокруткой внутри блока, без прокрутки страницы.

### Карточки тем на главной ведут сразу в чат
- **Наблюдение:** с коммита 9dc5a6f карточки тем открывают чат без шага дыхания. Правка пришла вместе с изменениями в `js/screens/home.js` во время работы, оставлена как намеренная. Кнопка «Мне плохо прямо сейчас» по-прежнему ведёт к дыханию.
